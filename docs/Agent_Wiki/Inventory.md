## ROS Packages

- `ball_tracking_cpp` (`src/Ball_Tracking_Cpp`): Event-based 3D ball tracking with a DVXplorer camera.
- `ball_tracking` (`src/ball_tracking`): Python utilities for the ball tracking workspace.
- `ur3e_catch_msgs` (`src/ur3e_catch_msgs`): Typed, timestamped message contract shared between the event-camera perception and the UR3e live-catch loop (BallState, CatchTelemetry). See docs/Robot_Control/ur3e_live_catch_architecture.md §5.
- `ur3e_live_catch` (`src/ur3e_live_catch`): Single-process live closed-loop ball-catch node for the UR3e: ball-frame transform, 33-D observation reconstruction, PPO policy runtime, plus an artificial test-ball source, native ball_tracking_cpp launch support, and a legacy Float32MultiArray->BallState adapter. See docs/Robot_Control/ur3e_live_catch_architecture.md §4.3.
- `ur3e_rollout_replay` (`src/ur3e_rollout_replay`): Validate and replay Isaac rollout joint targets on a UR3e through FollowJointTrajectory.
- `ur3e_sysid` (`src/ur3e_sysid`): UR3e actuator system identification (Option B): an online sweep stage that excites one joint at a time (step/ramp via the trajectory action, chirp via forward_position_controller @60Hz) and records /joint_states, plus an offline estimator that fits the closed-loop surrogate gains (K, D), pure delay L, effective inertia and friction into ur3e_actuator_identified.yaml for Isaac. See docs/Robot_Control/ur3e_programme_identification_gains.md.
- `ur3e_web_ui` (`src/ur3e_web_ui`): Browser UI for the UR3e: live 3D model, jog control, TCP pose, and Isaac rollout replay.
